# Research Documentation Organisation Template

This repository provides a reusable folder structure for organising and managing the documentation associated with a thesis or dissertation project, from initial ideation through to final submission. It serves as a central workspace for research planning, literature reviews, administrative records, artefact documentation, and dissertation drafts.

**This repository is intended for documentation only.** Application source code, implementation files, and development-related resources are maintained separately in the relevant code repository. This repository may contain links and references to those resources where necessary.

Each top-level folder contains its own README describing its purpose and usage.

## Folder Structure

- `Meta/` – Governing documents defining the project scope, assessment rubric, deadlines, and official guidelines.
- `Brainstorm/` – Early-stage ideas, scope iterations, research questions, and rejected directions.
- `References/` – Literature tracking, research papers, reading notes, and citation metadata.
- `Templates/` – Reusable templates for reports, proposals, presentations, and document formatting.
- `Administrative/` – Supervisor meeting notes, approvals, ethics documentation, and formal institutional correspondence.
- `Dissertation_Drafts/` – All dissertation writing stages, from the initial proposal through interim drafts to the final submission.
